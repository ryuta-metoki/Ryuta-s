# 街頭インタビュー風の読者調査ガイド

商品がない段階で、読者の「いまの悩みと、いまのやり方」を聞くための手順。売り込まず、過去の事実を聞く。

## 進め方
1. 入口: note・Xの末尾に一問だけ置く。「いま仕事で一番時間を取られていることは何ですか?」
2. 声をくれた人に、15分の対話をお願いする(チャット可)。強い誘導や特典での釣りはしない。
3. 対話後、その日のうちに `記録テンプレート` で要点をまとめ、リサーチ部に渡す。

## 質問の型(過去の事実を聞く)
- 直近でそれが起きたのはいつですか。何があって、どうしましたか。
- いまはどうやって対処していますか。何を使っていますか。
- それに、どのくらい時間やお金をかけていますか。
- いちばん面倒だった瞬間はどこですか。
- 他に試したことはありますか。やめた理由は何ですか。

## 避けること
- 「こういうサービスがあったら使いますか」(未来の仮定は当てにならない)
- アイデアの説明や売り込み
- 誘導する質問(「○○で困っていますよね?」)

## 記録テンプレート
- 相手の属性(職種・規模・経験。個人が特定されない形で)
- 悩みの内容と、直近の具体例
- 今のやり方と、かけている時間・お金
- 一番強く出た言葉(原文のまま)
- 次にやること

## 担当部署での使い方
- リサーチ部: 集まった記録から、悩みの共通点と頻度をまとめる(週次レポートに入れる)。
- 発信部: 頻出する悩みを、次のnote・Xのテーマにする。
