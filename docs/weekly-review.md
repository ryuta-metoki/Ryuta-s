# 週次レビュー: agent.md を育てる

agent.md は書いて終わりにしない。週1回、15分で次を回す。

1. `runs/` の今週分を開き、各体の出力を見る。
2. 次の表で、弱かった体を1つだけ選ぶ。

| 症状 | 直す場所 |
|---|---|
| 角度が浅い、既出ネタと被る | strategist の「良い仕事の定義」と「書かないこと」に具体例を足す |
| 反証データが角度を補強しているだけ | researcher の「良い仕事の定義」に「反証と誤分類しやすい例」を足す |
| ブリーフを無視した、字数がずれた | writer の役割に禁止事項を足す |
| 削りが甘い(25%未満) | editor の `変更ログ` を見て、残った重複パターンを役割に書く |
| プラットフォーム仕様違反 | publisher の整形ルールに具体的な数字を足す |
| 体の間で聞き返しが出た | `templates/handoff.md` の該当項目か申し送りの書き方を直す |

3. 直したら、このファイル末尾に1行ログを残す(日付 / 体 / 何を足したか / 理由)。
4. 同じ症状が2週続いたら、役割ではなく入力(`input.md` の書き方)を疑う。
